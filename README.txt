MY FIT — Personal Fitness Tracker

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. Use the left/top navigation to open Dashboard, Workout, Nutrition, Body Measurements and Calendar.
4. Your entries are automatically saved in this browser on this device using localStorage.
5. Use the top-right download/upload icons to export or restore a JSON backup.

IMPORTANT
- This is a client-side website. It does not upload your information to a server.
- Browser data can be lost if browser storage is cleared, so export backups regularly.
- If you open it on another device or browser, the data does not automatically sync.
- Nutrition values are user-entered estimates. Verify serving sizes and food nutrition values.
- The 2,350 kcal / 160g protein values are starting targets, not medical advice. Adjust based on several weeks of progress, training performance and individual needs.
- Exercise loads and reps should be chosen with safe technique. Stop if you experience pain, dizziness or unusual symptoms.

CUSTOMIZE
Edit the workout plan in app.js (the `plans` array) and nutrition targets in app.js / index.html.

IPHONE HOME SCREEN / OFFLINE APP
This package is PWA-ready. To install on iPhone:
1. Publish the contents of this folder to an HTTPS website (GitHub Pages is a free option).
2. Open the published website URL in Safari.
3. Tap Share (square with arrow) -> Add to Home Screen -> Add.
4. Open MY FIT from the new Home Screen icon once while online. The app shell is cached for offline use.
The iPhone Files preview is not the correct way to run this website. It may show unstyled HTML.
